# Hematology Dry Practical Lab – Version 1

Free mobile-friendly Progressive Web App (PWA) for MLT students.

## Included
- Practical learning modules
- RBC/WBC/platelet chamber calculator
- RBC indices: MCV, MCH, MCHC
- Reticulocyte and corrected reticulocyte calculators
- INR calculator
- 10-question randomized MCQ quiz
- Viva trainer
- Offline cache via service worker
- Installable PWA manifest

## Run
Upload all files to an HTTPS static host (for example GitHub Pages or Netlify), or test with a local web server.

Opening `index.html` directly with `file://` can display the app, but service-worker/offline and PWA installation require a secure context such as HTTPS or localhost.

## Educational note
This is a dry-practical educational simulator. It is not a diagnostic device and does not replace institutional SOPs, supervised practical training, quality control, or professional judgment.
